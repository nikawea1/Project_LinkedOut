# LinkedOut (ЛЕНТЯIN)

> **Концептуальная профессиональная социальная сеть для ценителей осознанного отдыха и мастеров прокрастинации.**  
> Ироничная альтернатива классическим деловым сетям: здесь делятся рекордами лени, спасёнными от бессмысленных совещаний часами, конвертируют корпоративные табели в лень-баллы и уверенно растут в рангах от *Middle Slacker* до *Expert Fired*.

## Ключевой функционал платформы

### 1. Импорт и аудит корпоративных табелей (Excel / SheetJS)
- **Drag-and-Drop дропзона:** парсинг рабочих файлов `.xlsx` с автоматической валидацией формата (неподходящие форматы отклоняются с информативным модальным окном).
- **Конвертер времени:** расчёт спасённых от выгорания часов и автоматическое начисление лень-баллов.
- **Генерация демо-шаблона:** возможность в 1 клик скачать готовый `.xlsx` файл для тестирования.

### 2. Социальная лента и профили
- Создание публикаций (отговорки, рекорды, новости об увольнении).
- Интерактивные реакции (лайки) и ветки комментариев.
- Персональные карточки с рангами и биографией.
- Быстрый вход под тестовыми профилями для демонстрации.

### 3. Реестр задач и панель управления Voyager Admin
- Таблица активности с поиском, фильтрацией по статусам и категориям.
- Постраничная навигация и режим «Ленивой подгрузки» (+10 строк без лишних кликов).
- Переиспользуемый модальный компонент для создания и редактирования записей.
- Журнал аудита с визуальным сравнением состояний до и после (JSON Diff).
- Управление рангами членов гильдии и модулем хранилища (Local Storage / Google Drive).

### 4. Интерактивные разделы
- **Канбан-доска «Отложено»:** классические колонки *To Do / In Progress / Done* с нативным HTML5 Drag-and-Drop и модальным созданием задач.
- **Мессенджер:** список активных чатов, обмен сообщениями и автоматические остроумные ответы коллег.
- **Дашборд аналитики:** KPI-карточки с трендами, интерактивный график за 12 дней и история транзакций.
- **Магазин товаров и мерча:** каталог с поиском, фильтрами, слайдером цен, пагинацией и 4-шаговым мастером оформления заказа со скидками до 20%.
- **Дизайн-система:** витрина токенов, кнопок, инпутов, бейджей и модальных окон.

## Архитектура и стек технологий

- **Frontend:**
  - **Vue 3** (Composition API, реактивное состояние, Single File Components).
  - **Tailwind CSS 3.4+** (контейнерные запросы `@container`, псевдоклассы `:has()`, утилиты `@apply`, кастомная архитектурная палитра индиго/золото).
  - **SheetJS (xlsx.full.min.js)** для надёжной клиентской обработки электронных таблиц.
  - **Авторская SVG-иконографика** (единый штрих 1.8px, абсолютный отказ от стандартных эмодзи в пользу дорогого минимализма).
- **Данные и персистентность:**
  - Клиентская реляционная база данных (`js/db.js`) с поддержкой сессий, таблиц и экспорта/импорта полного дампа в JSON.
  - Двойная совместимость: сайт работает как **полноценное статическое приложение (Jamstack / Cloudflare Pages / GitHub Pages)**, так и в связке с backend-сервером.
- **Backend:**
  - Встроенный сервер на Node.js (`server.js`) с версионированным REST API (`/api/v1/tasks`, `/api/v2/audit-log`) и сохранением в локальный файл `db.json`.

## Локальный запуск и разработка

### Требования
- Установленный **Node.js** версии 18 или новее.

### Установка зависимостей
```bash
npm install
```

### Сборка стилей и статики
```bash
npm run build
```

### Запуск в режиме разработки (Hot-Reload стилей)
```bash
npm run dev
```

### Запуск полного стека (Static + REST API Server)
```bash
npm start
```
Сервер будет доступен по адресу: **`http://localhost:3000`**

- Главная страница: `http://localhost:3000/index.html`
- Реестр задач и Voyager Admin: `http://localhost:3000/data-hub.html`
- Лента: `http://localhost:3000/feed.html`
- REST API v1: `http://localhost:3000/api/v1/tasks`
- Журнал аудита v2: `http://localhost:3000/api/v2/audit-log`

## Развёртывание (Deployment)

Проект полностью оптимизирован для бесплатного хостинга без региональных ограничений:
1. **Cloudflare Pages:** подключение репозитория GitHub, Build command `npm run build`, Output directory `dist`. Неограниченный трафик и поддержка `_redirects`.
2. **GitHub Pages:** автоматический деплой через настроенный рабочий процесс `.github/workflows/deploy.yml`.
