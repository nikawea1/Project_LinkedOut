# LinkedOut

Творческий концепт социальной сеть в стиле LinkedIn для прокрастинаторов. Включает ленту постов, интерактивную канбан-доску дедлайнов, мерч-шоп с корзиной, многошаговый чекаут, мессенджер и тёмную тему. Реализован на HTML5, Tailwind CSS и JavaScript.

## Основные возможности

**Лента и публикации**
- лента постов и рекордов прокрастинации с лайками и комментариями
- интерактивные бейджи и ранги лени
- фильтрация публикаций по категориям и тегам

**Канбан-доска дедлайнов**
- интерактивная доска задач с колонками: «В планах», «В процессе», «Отложено»
- карточки с индикаторами дедлайнов и уровня лени
- модальное окно добавления новых задач и перенос между колонками

**Магазин и оформление заказа**
- каталог товаров для комфортного отдыха
- интерактивная корзина с динамическим пересчётом стоимости
- 4-шаговый чекаут: личные данные, доставка, способ оплаты и подтверждение с валидацией полей

**Личный кабинет и мессенджер**
- профиль с уровнем лени, счётчиком прокрастинации и коллекцией ачивок
- диалоги и список контактов с перепиской
- формы входа и регистрации с переключением видимости паролей

**Дизайн-система и интерфейс**
- переключатель тёмной и светлой темы с сохранением в localStorage
- кастомный Web Component `<ad-slot>` для баннеров
- страница `design-system.html` с токенами цветов, шрифтами, кнопками и элементами форм

## Технологии

- HTML5, семантическая разметка
- Tailwind CSS 3.4
- JavaScript
- Web Components, Vue 3
- Vite, Cloudflare Pages
- GitHub Actions CI/CD

## Как запустить

### Простой просмотр
Открыть `index.html` в любом современном браузере.

### Для разработки
Нужен Node.js

1. Установить зависимости:
   ```bash
   npm install
   ```

2. Запустить режим сборщика стилей:
   ```bash
   npm run dev
   ```

3. Собрать проект:
   ```bash
   npm run build
   ```
