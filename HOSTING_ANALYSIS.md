# Сравнительный аналитический отчёт: выбор бесплатной хостинговой платформы для статического проекта на Vue + Tailwind CSS с интеграцией рекламных блоков

**Проект:** Социальная сеть мастеров прокрастинации «ЛЕНТЯIN»  
**Стек:** Vue 3 (Composition API / SFC) + Tailwind CSS 3.4+ + SheetJS + Vite / Vanilla ESM  
**Сценарий развёртывания:** Статический веб-сайт (Jamstack / MPA / SPA) с клиентской базой данных, компонентом рекламного плейсхолдера (`AdSlot.vue`) и перспективой монетизации через показ партнёрских баннеров.  

---

## 1. Контекст и цели анализа

При публикации современного веб-приложения на бесплатных тарифах облачных хостинг-провайдеров разработчики сталкиваются с рядом строгих юридических и инфраструктурных ограничений (Terms of Service / Acceptable Use Policy). Особенную сложность представляет внедрение рекламных интеграций (Google AdSense, рекламные сети, партнёрские баннеры, слоты спонсоров). Нарушение политик сервиса способно повлечь мгновенную блокировку проекта, отключение доменных имён или заморозку учётной записи.

Цель настоящего отчёта — провести сравнительный анализ пяти популярных бесплатных платформ хостинга статических сайтов, выявить скрытые риски коммерческого использования и рекламы, сформулировать однозначную рекомендацию для проекта «ЛЕНТЯIN» и аргументировать архитектурный выбор.

## 3. Анализ рисков пользовательских соглашений (Terms of Service & AUP)

### 3.1. Vercel: Критический риск блокировки на тарифе Hobby
Пользовательское соглашение Vercel прямо разграничивает тариф Hobby (предназначенный исключительно для персонального, образовательного и некоммерческого применения) и платный тариф Pro. В пункте соглашения об Acceptable Use указано, что любая деятельность, приносящая доход владельцу сайта (включая кликбейтные баннеры, партнёрские ссылки с реферальными выплатами и блоки Google AdSense), трактуется системой аудита Vercel как **Commercial Activity**. При обнаружении рекламного кода на аккаунте Hobby Vercel направляет требование принудительного апгрейда на тариф Pro ($20/мес за каждого участника) либо приостанавливает обслуживание без предварительного предупреждения. Для бесплатного проекта с рекламным слотом Vercel представляет собой зону наивысшего риска.

### 3.2. GitHub Pages: Риск попадания в «серую зону»
В официальном руководстве GitHub Pages («Guidelines for GitHub Pages») зафиксировано: хостинг не предназначен для ведения коммерческого бизнеса или организации интернет-магазинов с платёжными транзакциями. При этом GitHub официально разрешает принимать спонсорские пожертвования и размещать умеренные баннеры, если проект сохраняет характер образовательного, научно-исследовательского или персонального. Однако если трафик сайта возрастает, а соотношение полезного контента и рекламы сдвигается в сторону рекламного блока, проект может быть признан «платформой, ориентированной главным образом на рекламу», что нарушает AUP GitHub и ведёт к удалению страницы или бану репозитория.

### 3.3. Netlify: Кредитная модель 2026 года и юридическая неопределённость
Хотя представители службы поддержки Netlify на официальном форуме заявляли о лояльности к рекламе на бесплатном уровне, в тексте официального публичного лицензионного соглашения чёткое закрепление коммерческого иммунитета отсутствует. Более того, переход Netlify к системе расчёта ресурсов на основе совокупных кредитов (Bandwidth + Build minutes + Functions) создаёт риск мгновенного исчерпания месячной квоты при всплеске визитов на рекламные страницы, после чего сайт блокируется заглушкой 402/404 до наступления следующего расчётного цикла.

### 3.4. Cloudflare Pages: Наиболее безопасная и предсказуемая среда
Политика Cloudflare Pages строится на предоставлении глобальной периферийной сети (Anycast Edge CDN). В условиях бесплатного использования Cloudflare Pages отсутствуют ограничения на монетизацию статического контента. Наличие неограниченного входящего и исходящего трафика (Unmetered Bandwidth) гарантирует, что даже вирусный охват страниц с рекламой не приведёт к внезапному счёту за трафик или заморозке аккаунта. Кроме того, Cloudflare обладает иммунитетом к односторонним блокировкам и обеспечивает стабильную доступность из любых регионов.

## 4. Итоговая рекомендация для проекта «ЛЕНТЯIN»

Для развёртывания проекта «ЛЕНТЯIN» на стеке Vue + Tailwind CSS с интегрированным рекламным блоком `AdSlot.vue` **однозначно рекомендуется выбрать Cloudflare Pages в качестве основной платформы**. В качестве альтернативной (запасной) платформы рекомендуется использовать **GitHub Pages**.

### Обоснование выбора Cloudflare Pages:
1. **Абсолютная юридическая безопасность по отношению к рекламе:** Бесплатный тариф Cloudflare Pages официально разрешает размещение сторонней рекламы и коммерческих интеграций, исключая риск внезапной блокировки по признаку «коммерческой активности».
2. **Неограниченная пропускная способность:** В отличие от других сервисов с лимитом 100 ГБ, Cloudflare не тарифицирует объем переданных данных, что критично для социальной сети с изображениями мерча, аватаров и медиафайлов.
3. **Безупречная интеграция с рабочим процессом Vite / Node.js:** Сборка запускается командой `npm run build` с выводом в директорию `dist`, а маршрутизация статических страниц и редиректов нативно поддерживается через конфигурационный файл `_redirects` и `wrangler.toml`.

## 5. Ключевые факторы принятия решения

При принятии архитектурного решения были расставлены следующие приоритеты:
1. **Приоритет №1: Соответствие юридическим политикам монетизации (Policy Compliance).** Для проекта с компонентом `AdSlot.vue` недопустимо использовать хостинги (вроде Vercel Hobby), на которых показ рекламы является прямым нарушением договора оферты.
2. **Приоритет №2: Устойчивость к перерасходу трафика (Traffic Resilience).** Бесплатный неограниченный трафик Cloudflare снимает необходимость постоянного мониторинга квот и предотвращает «эффект внезапного отключения» при посещении сайта большим числом пользователей.
3. **Приоритет №3: Простота CI/CD и доступность без региональных ограничений.** Автоматический деплой при каждом коммите через Git-репозиторий в сочетании со 100% стабильностью доступа платформы в СНГ позволяет команде сосредоточиться на качестве кода и дизайна.
